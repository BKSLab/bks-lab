## Этап 1 — backend: контент, БД и API `[x]`

- Слои по `docs/FASTAPI_PATTERNS.md`: api → services → repositories →
  {content | PostgreSQL}; DI в `dependencies/` (шов для
  `app.dependency_overrides` в тестах).
- Markdown-репозитории трёх типов контента (`articles`, `notes`, `projects`):
  парсинг frontmatter, валидация Pydantic, рендеринг Markdown → HTML (GFM).
- **Механика синхронизации** (`docs/architecture.md` §3): TTL-проверка mtime
  (5 с), `asyncio.Lock` single-flight, полный рескан типа, `content_hash`
  для пропуска неизменённых, одна транзакция upsert+delete, при ошибке БД
  кэш не обновляется.
- **Проекция `content_items`**: маппинг статусов по `docs/content_format.md`
  (draft → `draft`, archived только проекты, невалидный файл удаляется);
  `reading_time` из `word_count`.
- PostgreSQL: async SQLAlchemy + asyncpg, Alembic-миграции (прогон
  `alembic upgrade head` в entrypoint, как в референсе), модели
  `page_views` (+ индексы), `content_items`.
- `POST /api/v1/stats/pageview`: белый список шаблонов path (202 без записи
  вне списка), нормализация (query обрезается, якорь `#note-<slug>` →
  `note_slug`), insert через BackgroundTasks (202 сразу), `visitor_hash`
  (HMAC-дневная соль, инъецируемые часы), фильтр ботов, rate-limit,
  IP из forwarded-заголовков.
- `/api/health`: `SELECT 1`, 503 при недоступности БД.
- Скрипты `backend/scripts/new_article.py`, `new_project.py`, `new_note.py`.
- Эндпоинты P0 по `docs/api_contract.md`: `/articles` (+category, +q,
  пагинация), `/articles/latest`, `/articles/{slug}`, `/notes`,
  `/notes/latest`, `/categories`, `/projects` (+featured),
  `/projects/{slug}`.
- Стартовый контент: 6 статей, 3–5 заметок и 3 проекта из дизайн-ТЗ §10–§11
  (тексты могут быть черновыми, frontmatter — полный и валидный).
- Тесты pytest + httpx: контракт каждого эндпоинта, пагинация и её границы
  (`page` вне диапазона → 200 пусто), `q` (min_length, регистр), фильтры,
  404; запись pageview (белый список, якорь → `note_slug`, хэширование,
  боты, rate-limit); синхронизация (рескан по изменённому `os.utime` на
  `tmp_path`-фикстуре; удаление файла удаляет запись; невалидный frontmatter
  исключает из API и проекции; параллельные запросы → один рескан).
  Репозитории БД — на testcontainers, по `docs/FASTAPI_PATTERNS.md`.

**DoD:** все эндпоинты P0 отвечают по контракту на стартовом контенте;
pageview пишется в PostgreSQL, IP в БД отсутствует; `content_items`
синхронизируется с файлами (добавил файл — появилась строка, удалил —

проходе с учётом первого ревью Kimi. Pytest: 175 passed на PostgreSQL 16,

Применимая часть чек-листа ТЗ §22:

| Проверка | Результат |
|---|---|
| Клавиатура: Tab/Shift+Tab, Enter, Escape, skip-link, H1 после перехода | Пройдено автоматизацией реального Chrome; меню не перекрывает фокус футера |

| Контраст | Проверены тёмная и светлая темы, основные тексты, ссылки и кнопки |
| Reflow и размер текста | Нет горизонтального переполнения на 320 CSS px; проверены tablet/desktop и увеличение текста до 200% |
| Browser zoom 200% | Эмуляция 640 CSS px при scale 2 пройдена; нативный zoom вручную не проверен |
| Reduced motion, forced-colors | Проверены через эмуляцию media features; фокус и основные действия различимы |
| CSS и изображения отключены | Структура, заголовок и смысл страницы сохраняются |
| NVDA + Chrome/Firefox | Не проверено; требуется ручной проход header, меню, skip-link и клиентских переходов |
| VoiceOver/Safari или TalkBack/Chrome | Не проверено; требуется базовый ручной сценарий |

Hero, карточки, фильтры, поиск и формы проходят применимые проверки
